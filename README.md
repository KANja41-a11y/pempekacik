# Pempek Acik — Website Promosi

Website landing page elegan untuk brand **Pempek Acik**.

## Fitur
- Hero section + CTA
- Tentang produk
- Menu & harga (mulai Rp10.000)
- Paket (Solo, Keluarga, Hajatan)
- Tombol pemesanan WhatsApp & Instagram
- Desain mewah & responsif
- Siap di-host di GitHub Pages

## Cara Ganti Kontak
Buka `index.html`, cari bagian:
- `https://wa.me/6281234567890` → ganti dengan nomor WhatsApp asli
- `https://instagram.com/pempekacik` → ganti username Instagram

## Deploy ke GitHub Pages
1. Buat repository baru
2. Upload `index.html`
3. Settings → Pages → Deploy from branch `main`
